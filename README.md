# NLP_2025 – Lab Repository

## Giới thiệu
Repository này lưu trữ **toàn bộ bài tập lab của môn NLP**, được tổ chức **theo từng tuần (week)** tương ứng với tiến độ học trên lớp.  
Mỗi thư mục `weekX` chứa **code, notebook và/hoặc báo cáo** cho các lab được giao trong tuần đó.

Mục tiêu của repository:
- Tổ chức bài tập **rõ ràng, dễ theo dõi**
- Giúp người xem **nhanh chóng hiểu nội dung từng lab**
- Phân tách rõ **code – report – notebook**
